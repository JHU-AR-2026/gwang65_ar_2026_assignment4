## How to Run

### Q1
Requires Python, NumPy, and Matplotlib.

Install dependencies:

    python3 -m pip install numpy matplotlib

From the repository root, run:

    python3 Q1/Q1e/Q1e.py
    python3 Q1/Q1f/Q1f.py

### Q2
1. Open Unity Hub.
2. Add the Q2 folder as a project.
3. Open it using Unity 6000.6.5f1.
4. Open Assets/Scenes/SampleScene.unity.
5. Press Play to run the game.
